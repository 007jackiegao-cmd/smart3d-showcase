# SMART3D｜参数化建模与装配工作台

**让三维模型保留它的设计逻辑。**

SMART3D 围绕构件定义、参数驱动、实例装配与信息输出组织设计流程。尺寸变化不仅改变外观，也能沿同一条链路更新几何、物料数量与模型文件，便于检查设计输入和输出之间的关系。

## 公开演示

当前演示提供法兰和安装板两类合成构件。可以修改尺寸、中心孔、孔距、孔径和孔数，触发真实的网格布尔计算；也可以切换到示例装配，查看物料数量与基于密度假设的质量估算，再导出 GLB、CSV 或参数 JSON。

界面采用浅色工程工作台：左侧呈现构件与特征树，中间保留三维操作空间，右侧集中参数与输出。截图来自可运行界面，不使用概念图代替已实现功能。

## 项目架构

原项目采用 Vue 3 / TypeScript / Three.js 前端、FastAPI / Python / Manifold / SQLAlchemy 后端与 PostgreSQL 持久化层。源码中包括构件版本、表达式、几何插件、装配、BOM、发布查看器及租户管理模块。此次公开包是重新整理的前端演示，核心后端与原始资料保留在本地私有工作区。

自然语言建模目前只定义了对接契约，解析接口尚未启用。完整服务端应用和数据库链路未在本次包装中完成部署验证，因此没有将规划中的性能指标、权限设计或 AI 能力描述为已验证成果。

## 验证与边界

原项目选取的 75 项几何、表达式、布尔、轮廓、导出和节点拆分测试在隔离环境通过。公开演示的 12 项计算检查通过，浏览器导出的装配 GLB 已读回验证。具体范围见 VALIDATION.md。

演示数据、模型编号与物料均为合成样例。公开包不包含个人信息、真实用户、数据库备份、原始模型档案、运行缓存、环境配置或凭证。项目内容去身份化，平台用户名与提交元数据仍属于托管平台信息。
